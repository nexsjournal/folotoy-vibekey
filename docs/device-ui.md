# Passport 设备界面设计

本地分支无线交互：首次在 Mac 设置 › Passport 配置 2.4 GHz Wi-Fi；设备和 Mac 处于同一局域网后，状态栏显示 `WIFI`，USB 在位时仍优先显示 `USB`。Mac 显示“Wi-Fi 已就绪，拔线后自动切换”才表示完成无线应用层握手。设备最多保存 4 个网络，换网不需要 Mac。离线继续显示原 OFFLINE/WAITING FOR MAC 页面。配网后本轮启动使用 Wi-Fi，未配网使用 BLE；Wi-Fi 已配置但 25 秒拿不到 IP 时自动重启到 BLE 单栈并显示 `BLUETOOTH MODE / HOLD DOWN`。长按 ▲ 约 1 秒切换听写、翻译、字幕模式，继续按住到约 2.5 秒打开网络菜单；蓝牙模式或完全离线时也可长按 ▼ 直接打开。最后一项 `USE BLUETOOTH` 会保留配网记录并立即切到蓝牙。Wi-Fi 正常在线时长按 ▼ 仍用于 Agent 应用 / 项目 / 会话导航。蓝牙在线时选择已保存的 Wi-Fi（包括当前标记项）会清除蓝牙模式并重启尝试 Wi-Fi，Wi-Fi 离线时选择当前网络也会重试。手动蓝牙在插回 USB 后不会被强制切回；自动回退到蓝牙时，插回 USB 会自动恢复 Wi-Fi。

长按下键打开「应用 / 项目 / 会话」导航：普通应用直接显示应用列表；当前是 Codex 或 DeepSeek Honeycomb 时，先显示项目和最近会话，选中项目后再选会话。选中会话会打开它并把光标放回输入框。目标应用由这个列表记住（默认 Codex）。按住 OK 立即采音，同时前置并聚焦所选应用；松开后识别/翻译并输入。Mac 正常采音为绿色，启动为黄色，错误为红色；硬件原有 Matrix 视觉不变。


## Matrix 视觉开发中

当前开发版在 IDLE、REC、PROC、DONE、ERR 页使用终端式标题和绿色点阵边框；OFFLINE 也使用终端标题和绿色时钟。前三页分别显示 `> READY_`、`> LISTENING`、`> DECODING_`；DICTATE 待机显示 `HOLD OK TO TALK`，录音页根据按键状态提示松开或再按一次 OK。SUB、LIST、USAGE 和 Agent 通知沿用同一套点阵语言。除专用审批页外，核心状态页已实现并通过 46 个 LVGL 主机场景检查；实体屏幕的完整状态巡检仍待验收。

屏幕 ST7789 240×320 竖屏,LVGL 9;状态文本主要为 ASCII,SUB 字幕与 LIST 项目 / 会话名保留 UTF-8(12 px SemiBold 中文字库)。终端标题与主要操作提示使用 Roboto Mono,其余文字仍使用 Montserrat。交互页页脚显示同步时钟,未知时为 `--:--`。**不显示转录内容**,用动画表达状态。

设计原则(固件 0.1.2 起,「点阵」主线):**一屏只突出一件事**,整个界面的主体只用**一种图元——8 px 网格上的 5×5 圆点**。模式图标、录音声波、处理中的扫描光、完成 / 失败、离线时钟、电量,全由同一批点组成;点阵页面之间切换时点"重排"(morph),听写全过程(模式图标 → 一条线 → 声波 → 一条线 → 图标)是一段连续的粒子动画。终端标题和主要操作提示采用等宽字体。纯黑底,主交互页逐步采用终端绿,录音、失败等保留语义色。

## 点阵网格

- 25 列,列 c 的点心 x = 内容区居中线 − 96 + 8c(c = 12 落在居中线);行 r 的点心(屏幕)y = 28 + 8r;声波 / 线在第 13 行(y 132)。点 5×5、圆角 2。
- 字形(固件 `ib_ui_dots.c`,X = 点):mic(9×10)、translate 两个对话气泡(9×10)、CC 框(9×7)、对勾(11×8)、叉(9×9)、感叹号(3×10)。
- 重排:两个图案各按列优先排序后按序号配对(数量不同时循环复用),每颗点按目标列号错峰 6 ms 起飞,240 ms ease-in-out-cubic 飞到新位置并渐变颜色,飞行中略微放大;整段 ≤ 384 ms。从声波页离开时先用 120 ms 把声波按行塌缩成一条线,再从线重排。
- 主体是点阵的页面(IDLE / REC / PROC / DONE / ERR / SUB)之间"直切":旧页立即隐藏,新页接着上一页的最后一帧让点重排(`ib_ui.c`、`ib_ui_page.h` 的 `prev_screen`)。OFFLINE / LIST / Agent 与它们之间仍是 fade-through(旧页 120 ms 淡出、新页 180 ms 淡入并上移 8 px)。

## 布局

顶部 24 px 状态栏;在线页面右侧 22 px 是按键提示列,页面内容只用左侧 218 px 并在其中水平居中;离线时钟和 Agent 全屏通知使用整屏宽度。主要页面的一行文字位于 y=220;IDLE 和 REC 的提示使用 Roboto Mono 14。

### 状态栏

- 左:链路 `USB` / `WIFI` / `BLE`(12 px 字距 +1;在线 `#A0A0A0`，离线时保留 90% 不透明度)。录音时换成脉动红点 + 计时;字幕时换成闪烁白点 + `LIVE`。
- 右:电量是 **5 颗 4 px 圆点**(每颗 20%)。≤20% 且未充电时唯一亮着的点变红;充电时点从左到右循环点亮;**百分比数字只在低电量或充电时出现**。
- 充满:板上没有充电状态引脚,CW2017 的电量在恒压段会停在 9x%(实测 94%)。USB 在位、电量 ≥ 90% 且电压 ≥ 4.15 V 持续 10 分钟后(`main/ib_charge.*`),视为已充满:5 颗点全亮、不再循环点亮、百分比隐藏,上报 Mac 的电量为 100%;之后电压跌破 4.10 V(或电量低于 90%)才恢复按实际读数显示,拔掉 USB 不会立刻从 100% 跳回 94%。某次读数失败不影响这个判定。

### OFFLINE(Mac 未连接)

- 默认是橙帽绿外套的像素猫咪坐在绿色窗景和终端面板前，占据屏幕上部；底部约 110 px 暗区留给时钟。左上角使用 14 px 终端字体把 `> OFFLINE_` 直接叠在窗景上，顶部状态栏也叠在图上。背景为 240 × 320 的 RGB565 图，真机与主机预览共用 `firmware/main/assets/offline-cat.rgb565`。
- 自定义壁纸：设置 › Passport › 离线页背景选一张照片即可。Mac 端裁成 3:4、降到 60×80 后按 4×4 放大、Bayer 抖动成 24 级绿色，再把顶部 40 px 和底部从 y=200 起压暗；用户不需要预先做像素风。有效自定义图从 `wallpaper` 分区 mmap 读取，CRC 不符或没上传过时自动回退内置猫图。
- 底部桌面上显示绿色 5×7 点阵时钟，数字以 6 px 为点距。冒号每秒渐变，每帧只重绘冒号区域。日期在 y=301，底部提示在 y=313：有 USB、BLE 或已配网 Wi-Fi 时显示 `PRESS OK TO RECONNECT`，完全没有链路时显示 `CHECK USB CABLE`。
- 离线时按 OK 会通过当前 USB（或 BLE）发送 `wake`，让 Mac 重新握手；提示先变 `CONNECTING...`，3 秒无响应变 `NO RESPONSE - TRY AGAIN`，2 秒后恢复 `PRESS OK TO RECONNECT`。不需要拔插数据线。
- 离线时长按 ▼ 打开设备本地 `WIFI NETWORK` 列表：短按 ▲ / ▼ 选择，短按 OK 切换当前网络并重启 Wi-Fi，长按 OK 返回；30 秒无操作自动返回。列表只显示 SSID 和 `*` 当前标记，不显示密码或 PSK。没有已保存网络时长按 ▼ 显示 `USB TO ADD WIFI`。
- 进入条件:全部链路都离线(15 s 没收到命令、`bye`、USB 连续 1 s 不在位、BLE 断开)。Mac 空闲被 App Nap 挂起也会触发 15 秒超时;Codex 的消息 hook 会唤醒 VibeKey，所以有时“发一条 Codex 消息就自己连上”。离线不清除 Mac 下发的状态,恢复在线后回到离线前的页面(例如字幕运行中直接回到 SUB 页)。

### IDLE

- 当前模式的绿色点阵字形(dict = 麦克风、tr = 两个对话气泡、sub = CC 框);每 4 s 一道扫描光自上而下掠过(800 ms),经过的点变亮并略微放大。
- 模式提示(`HOLD OK TO TALK` / `TRANSLATE` / `SUBTITLES`,14 px,y=220)。引擎名、分页点都去掉了,操作提示由右侧按键提示列显示。
- 切换模式:点阵从旧字形重排成新字形;模式名纵向翻牌(旧名字 140 ms 内向上 / 下翻出淡出,之后新名字从另一侧翻入,两行字不叠在一起)。
- 字幕在运行时(不论设备在哪个模式),Mac 发 `state sub`,设备显示 SUB 页;字幕应用选择器复用 LIST 页(标题 `CAPTIONS`)。

### USAGE(Agent 用量首页)

- 从「切换应用」选中 Codex、DSH NEXT、WorkBuddy、ZCode、Claude、千问办公、豆包工作等 Agent 后,先显示这一页,而不是直接进入 READY。
- 顶部 `> CODEX` / `> DSH`;三行 Tab `TODAY / WEEK / ALL`,短按上下键切换;中间用 26 px 大号数字显示选中周期的 Token 数,下面只保留 `TOKENS`,不再重复 Tab 名称。整页文字统一左对齐,长数字不居中偏移。
- 下方是加高的两行信息区，两行额度之间留出独立说明行。Codex 显示 `5H LEFT` / `WEEK LEFT` 与进度条，并分别显示 `5H RESET` / `WEEK RESET` 倒计时，底部是 `PLAN` / `CREDITS`;DSH 显示 `CONTEXT` / `SESSIONS`、最近活动、模型和 `TURNS`;Claude / ZCode / WorkBuddy 显示各自的 sessions/turns/traces/spans、最近活动和模型。没有某项数据时不伪造,直接显示 `--` 或 `NO DATA`。
- 短按 OK 进入原 READY 页;长按 OK 直接从用量页开始录音;长按上键切模式;长按下键打开应用 / 项目 / 会话列表。
- OK 按下即开始采音，短按松开时取消采音并进入 READY，按住说话后松开结束。在线熄屏时使用 Passport 麦克风，按下即采音并点亮录音页；Mac 在 2 秒内确认 `rec`，期间迟到的 `idle` / `usage` 不会覆盖录音页；长按前松开立即退出，超时才停止采音并恢复原页面。
- 屏幕点亮时，READY / USAGE 的短按判定期间暂留原页面，避免短按切页时录音页闪现；按住超过 500 ms 后显示录音页，采音仍从按下时开始。
- READY 页有可用用量页时,底部显示 `TAP OK: USAGE`;短按 OK(<500 ms)返回用量首页,按住 OK 仍然是说话。
- 数据由 Mac 的 `usage` 命令下发;设备只排版,不解析金额或聊天内容。读取中显示 `READING USAGE...`,失败显示 `NO USAGE DATA`。

### REC

- 按下 OK:字形的点重排成一条线,中间那颗变成录音红;声波再从线上长出来(300 ms)。
- 点阵声波(`ib_ui_wave`,mirror):中央第 12 列是红色活柱,高度 = 当前音量(半高 0..7 颗,0.75 次方映射,每拍向目标靠近一半);每 100 ms 活柱存档成历史柱,历史柱整格跳向两侧并逐渐变暗(终端绿)。静音时就是一条点线,配合状态栏红点与计时,安静但明显在录。节拍按时间推进(33 ms 一拍),掉帧时补齐,流动速度不变。
- 按住 OK 时显示 `RELEASE TO FINISH`,松开后处于录音态时显示 `PRESS OK TO STOP`;翻译听写模式另显示 12 px `translate` 图标。

### PROC

- 声波按行塌缩成一条线,一段约 5 颗点长的青色亮光在线上来回扫(单程 1.2 s)。
- 上一句还在处理时**按键不可用**:右侧提示列整列画成禁用色(Mac 仍下发 OK 的麦克风图标),按下 OK 时不会开麦、不会开始新的一句,标记点闪红并左右抖动表示"不可用"(见「右侧按键提示列」)。Mac 端同时在处理中忽略 Passport 的 OK。

### DONE

- 只是一个状态,不是庆祝画面:线重排回当前模式的字形,点在飞行中变成完成绿,落地后 600 ms 内褪回 IDLE 的绿色——约 1.2 s 后切回 IDLE 时画面已经一样,无缝衔接。
- 下方一行绿色状态字:`DRAFT READY`(Codex 专用模式；只在回读 AX 确认同一输入框已包含完整识别文本后显示)、`TYPED`,或 Mac 下发的 `msg`(如 `COPIED`;翻译 / 润色失败但已输入原文时为 `NOT TRANSLATED` / `NOT POLISHED`,发送目标无法核对时为 `CHECK MAC`,由 `DeviceStateMapper` 给出),250 ms 起淡入并上移 6 px 到位。

### ERR

- 点重排成红色的叉,同时整体左右抖动 3 次(衰减);下方显示 `msg`(20 px,最多两行)。切回 IDLE 时叉再重排回模式字形。

### SUB

- 进入时点阵重排成 CC 字形;转场结束后隐藏点阵,显示字幕文字。状态栏左侧的 `LIVE` 徽章继续表示正在听。
- 顶部一行 12 px 应用名(UTF-8,支持中文,超长省略),下面用 12 px SemiBold 中文字体显示原文;开启翻译后,下半部分用终端绿显示译文。原文最多约 5 行、译文最多约 12 行,超出裁掉旧内容。
- 字幕文字来自 Mac 的 `caption` 命令;`live=1` 时译文略暗,表示最后一句还在变化。`STOP` / `TRANSLATE` / `HIDE` 由右侧提示列显示。

### 项目 / 会话（LIST）

Codex、DeepSeek Honeycomb、ZCode、Claude、WorkBuddy 以及其他带聊天输入框 + 侧栏的 Agent 都支持从设备继续切换项目与会话。列表仍复用 LIST 页，最多显示 6 行，长列表用左侧滚动条指示位置。

```
长按下键
 → CODEX PROJECT / WORKBUDDY PROJECT / …
     SWITCH APP          ← 回到普通应用列表
     RECENT              ← 最近会话（有则显示）
     * 当前项目 / 其他项目
 → 短按 OK 选项目 → 读取该项目会话（侧栏折叠时自动展开）
 → CODEX SESSION / WORKBUDDY SESSION / …
     * 当前会话 / 其他会话
 → 短按 OK → 打开会话、聚焦输入框 → READY TO TALK
```

- 项目或会话前面的 `*` 表示当前所在项，默认选中它；没有匹配时选第一项。
- 会话页长按下键返回项目页；项目页长按下键关闭。15 秒无操作自动关闭。
- 读取项目 / 会话时显示 `SCANNING`；打开会话时显示 `OPEN SESSION`。读取失败或没有会话时显示 `NO SESSIONS`。
- 会话页也支持 Codex 空项目的 `NEW CHAT`，选中后在该项目新建对话并聚焦输入框。
- 列表标题与项目 / 会话名保留 UTF-8，使用固件内置的 12 px SemiBold 中文字库；超出 180 px 行宽时末尾显示 `..`，不再转拼音。当前项仍用 `*` 标记。
- 只读取侧栏标题和窗口标题，不读取聊天正文；名称不写日志、不持久化。
- 不按 Bundle ID 白名单：任何 App 在长按时都会先探测「聊天输入框 + 左侧项目/会话」。Codex / DSH 用专用适配器，其余走通用 AX 启发式；探测失败就回退普通应用列表，不会阻塞听写。
- 折叠的项目选中后自动展开（Claude 的 `Toggle sessions for`、ZCode 的项目标题按钮）。读不到会话显示 `NO SESSIONS`。

## 右侧按键提示列

机身实体布局:电源键在左侧靠上;三个功能键在右侧,自上而下为 UP、DOWN、OK。提示贴着屏幕右边缘,与各自的实体键水平对齐(y ≈ 70 / 170 / 270):

```
          ┌──────────────────────┐
  电源 ▌  │USB              ●●●●●│
          │                  ↵ ⁚ │ ▐ UP    (y≈70)   图标 enter
          │   页面内容           │
          │   (左侧 218 px       │
          │    内居中)       ✕ ⁚ │ ▐ DOWN  (y≈170)  图标 esc
          │                      │
          │                  🎤⁚ │ ▐ OK    (y≈270)  图标 mic
          └──────────────────────┘
```

- 提示列宽 22 px(屏幕很小,提示只需要能认出来):每个键是一个 **12 px** 图标(Material Icons Round,Apache-2.0,中心 x=226),`#686868`,外加贴屏幕右边缘的 3 颗 2×2 竖排小点(间距 5,`#303030`),与界面的点阵语言一致。图标由 Mac 的 `keys` 命令按 id 选择(id 列表见 `protocol.md`);空字符串或未知 id 隐藏该键的提示。
- 默认 UP 使用发送图标、DOWN 使用停止图标;二者执行前都核对当前 Codex 目标,不是单纯发送 Enter/Esc。发送成功显示 `SENT`,停止成功显示 `STOPPED`;当前输入框为空时显示 `INPUT EMPTY`，没有运行任务时返回待机页,无法核对显示 `CHECK MAC`,回执不明显示 `UNSURE`。
- 图标字体由 `firmware/tools/gen-icon-font.sh` 从固定提交的上游字体生成(lv_font_conv,4 bpp):12 px 字体含 21 个按键提示字形(其中 ⌦ `del` 是把 backspace 水平镜像派生的字形;派生用临时 venv 里锁定版本的 fontTools,结果逐字节可复现),56 px 字体保留页面主图标字形表;两种字号来自同一张表,协议 id、固件枚举与字形一一对应。
- 按下某键:图标与 3 颗点 60 ms 冲到白,上下各多出一颗点,再用 240 ms 回落(共 300 ms),这是唯一的按键视觉反馈。
- **禁用**(PROC 页:上一句还在处理):整列画成更暗的禁用色;按下时改为"不可用"反馈——点 60 ms 内变红并左右抖动 3 次(360 ms),图标不亮起,让用户知道这次按键没有生效。
- 三个纵坐标(70 / 170 / 270)是固件 `ib_ui_hints.h` 里的常量 `IB_HINT_Y_UP/DOWN/OK`,实测偏差时只改这里。

## AGENT 通知层(vibe coding)

Mac 下发 `agent` 时,在任何页面上方弹出全屏通知层(录音中不打断录音,只在顶部显示 28 px 横幅,且不拦截按键;离开录音页后再转为全屏通知层)。横幅只占左侧内容区,内容为图标 + 来源名(如 `! Claude Code`),来源名过长时末尾显示省略号:
- 全屏通知的主体是大号点阵(节距 12、点 7 px):每颗点从屏幕外一圈沿自己的方向飞入拼成字形(按列错峰 8 ms,单颗 360 ms ease-out)。
- `done`:绿色点阵对勾,标题 `DONE`,下方来源名(如 `Claude Code` / `OK OPEN 项目名`),最多两行,超出末尾显示 `..`;15 s 自动关闭,所以不显示 `press any key`;提示音为上行三音。
- `input`:暗橙色(`#C88848`)点阵感叹号,整体亮度 2.4 s 周期呼吸,标题 `YOUR TURN`,下方 `press any key`;每 20 秒重复一次提示音,直到关闭。录音中的小横幅仍是圆形小图标(`!` 每 3 s 轻摇)+ 来源名。
- 出现时先用 100 ms 铺满黑色背景,再用 160 ms 淡入通知内容;关闭时先用 120 ms 淡出内容,再用 100 ms 撤掉背景。任何时刻通知内容都不会与下面的页面内容叠在一起。横幅整体 200 ms 淡入 / 淡出。
- Codex 完成卡显示 `OK OPEN <项目名>`。15 秒内短按 OK 打开原对话,看到 `READY TO TALK` 后按住 OK 录音,松开得到草稿,短按上键发送。Mac 胶囊也可点击打开。打开时会短暂显示进度，随后回到待机。手动换到另一条 Codex 对话后，下一次按住 OK 会录入新对话。其他按压关闭卡片;`done` 15 秒后自动关闭。

## 按键反馈

- 任何按键:右侧对应的提示图标与标记点亮起 300 ms;禁用时(PROC)改为闪红抖动的"不可用"反馈(见上文);离线页没有提示列,不显示反馈。
- 去抖:ADC 层连续 4 次采样(20 ms)落在同一电压窗口才认定按下 / 松开;同一个键松开后 60 ms 内的再次按下视为触点回弹,整次忽略。一次实体按压只上报一次 `down` 与一次 `up`。
- 熄屏状态下,在线听写 / 翻译模式的 READY、USAGE 页按 OK 同时点亮屏幕并正常处理，可按住直接说话；其余按键和页面只点亮屏幕。
- 点亮屏幕的来源只有:按键、Mac 下发 `state`、Agent 通知、链路恢复在线;Mac 定期重发的 `config` 不点亮屏幕。
- 提示音(config `sound=1` 时):开始录音是上行双音(880→1320 Hz,各 40 ms),结束是下行双音,完成是短促一声,由设备本地合成并通过扬声器播放。
