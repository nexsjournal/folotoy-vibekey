# 2026-11-07 21:25 — 修复空闲后误报 OFFLINE，并支持设备端重连

- 原因：InputBetter 是菜单栏 App，空闲时会被 App Nap 降频，`DeviceLink` 的 5 秒心跳可能停超过固件 15 秒超时；Codex 的 `UserPromptSubmit` hook 执行 `open -g folobutton-dev://agent?event=clear` 会唤醒 InputBetter，所以发一条 Codex 消息后设备又自动上线。USB 线本身没有断开。
- `AppState.launch` 持有 `userInitiatedAllowingIdleSystemSleep` activity，保持心跳但允许系统正常休眠；`shutdown` 释放。
- 新增设备 → Mac `wake` 消息：OFFLINE 页按 OK 时通过 USB / BLE / 已配网 Wi-Fi 发送；Mac 重置对应链路握手并重发 `hello`，随后补发 `config` / `state` / `keys`。
- OFFLINE 页底部提示：有链路时 `PRESS OK TO RECONNECT`，无链路时 `CHECK USB CABLE`；连接中显示 `CONNECTING...`，3 秒无响应显示 `NO RESPONSE - TRY AGAIN`，2 秒后恢复。

- 验证：固件主机测试通过；`tools/validate.sh` 编译通过（app 2,523,120 字节）；App 250 项测试与 10 项 AppUpdateKit 测试通过；固件已烧录，Developer ID 签名安装版已更新。真机 offline → OK 重连闭环待用户验证。
