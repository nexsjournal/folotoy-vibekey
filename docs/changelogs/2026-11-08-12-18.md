# 2026-11-08 12:18 — 修复自定义壁纸上下颠倒

- 原因：`WallpaperProcessor` 在把裁切后的图片画进 `CGBitmapContext` 前又做了一次 `translate + scale(y:-1)`。实际 CGBitmapContext 的第 0 行已经是输出顶部，这次翻转导致照片上下颠倒。
- 修复：移除额外翻转；暗带仍按输出像素的 y 坐标计算，顶部 / 底部位置不变。
- 回归测试：新增 `testKeepsPhotoUpright`，用上亮下暗的渐变图确认处理后仍是上亮下暗；App 285 项测试通过。
- 已重新构建并安装 `0.1.8 (9)`；固件无需改动。之前已写入设备的图仍是旧方向，重新选图并点「应用到 Passport」即可覆盖。
