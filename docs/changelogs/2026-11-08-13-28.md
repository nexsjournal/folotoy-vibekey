# 2026-11-08 13:28 — 修复 macOS 26 图标外圈浅色底板

- 原因：旧 `AppIcon.appiconset` 是 1024 画布内 822 px 的透明留白图标，macOS 26 会把这类 legacy `.icns` 放进默认浅色容器，看起来像黑图标外面多了一圈白框。
- 新增 `VibeKey/AppIcon.icon`（Icon Composer 格式）：深色 `#262626` 作为 fill，声波作为透明 layer；系统直接按 macOS 26 图标规范渲染，不再套浅色底板。
- 同时把 `.appiconset` 的所有 PNG 改成满画布不透明版本，作为旧路径 / 打包工具的 fallback。
- 验证：用 `NSWorkspace.icon(forFile:)` 渲染 `/Applications/VibeKey.app`，确认得到深色圆角图标 + 透明外边距，没有浅色底板；Finder 里选中态的高亮不属于图标本身。
- app `0.1.9 (10)` 已重新安装；固件未改。
