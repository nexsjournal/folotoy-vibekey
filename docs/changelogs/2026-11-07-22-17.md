# 2026-11-07 22:17 — Agent 会话导航改为通用 AX 解析，并修正中文听写误判英文

- 新增 `AgentSessionModels.swift` / `AgentAX.swift` / `AgentNavigationParser.swift` / `AgentSessionAdapter.swift`：
  把原来按 Bundle ID 写死的 Codex / DSH 逻辑拆成注册表 + 专用适配器（`CodexAgentSessionAdapter`、
  `DeepSeekAgentSessionAdapter`）+ 通用回退 `GenericAgentSessionAdapter`。通用解析只读 AX 角色、标题、
  位置和可点状态，先确认聊天输入框，再从侧栏 landmark / AXOutline / 列表行里找项目与会话；折叠项目按
  `Toggle sessions for` 或项目标题按钮展开。
- `DeviceBridge` 长按下键不再用 Bundle ID 白名单：当前前台 App 先尝试读项目 / 会话，读不到再回退普通应用列表；
  项目列表默认选中当前项目或第一个有会话的项目。
- `DebugHooks` 的 `IB_SESSION_PROBE` 支持任意 Bundle ID（保留 `codex` / `dsh` 快捷值），新增 `IB_NAV_TRACE=1`
  打印通用解析判定；新增 `AgentNavigationParserTests`（10 项，合成 ZCode / Claude / WorkBuddy 结构）。
- `AXSnapshot` 不再按 AXUIElement 去重：Chrome 会把同一节点挂到多个父节点下，去重后快照下标与真实
  `AXChildren` 错位，可能按到关闭按钮 / 命令面板。按下前额外核对子树里确有目标名字。
- `WhisperEngine` 的自动语言检测增加主语言偏置：2 秒内短句直接用系统首选语言，中文夹英文时按中文解码，
  检测失败不再默认英文；新增 `SpeechLanguageDetection` 与 6 项单测。
- `DeviceLink` 监听系统唤醒，唤醒后立即重探 USB 串口并重握手；`PassportSetupView` 的查找设备页增加
  「重新连接」，USB 已插但显示 OFFLINE 时不必拔线。
- `PassportPane` 的「语音输入目标」说明补充：Agent 应用选完应用后还能继续选项目和会话。
- 文档：`docs/architecture.md` 4b 调用链、`docs/device-ui.md` 项目 / 会话、`README.md`、`AGENTS.md`
  的 `IB_SESSION_PROBE` 说明同步更新；`Localizable.xcstrings` 重新生成。
- 验证：App 270 项测试、AppUpdateKit 10 项测试通过；完整链路 `IB_SESSION_PROBE` 在真实 ZCode（24 个项目）、
  Claude（4 个项目）、WorkBuddy（43 个项目）上读出侧栏；ZCode 展开项目读到 2 个会话，Claude 展开读到 1 个会话；
  ZCode / WorkBuddy / Claude 各打开一个会话均返回 true；ZCode 打开后 AXTextArea 获得焦点。
  冷启动 Electron 的首次建树超过 2 秒，探测重试延长到 4 秒（只有 `notReady` 才等，普通应用立即回退）。
- 已知限制：当前项 `*` 依赖 AXSelected / 窗口标题 / 主内容 AXHeading；ZCode、WorkBuddy 的标题固定，
  个别界面可能读不到当前项。设备列表仍只显示 ASCII（中文转拼音、23 字节）。
