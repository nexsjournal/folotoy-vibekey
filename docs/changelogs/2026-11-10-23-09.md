# 2026-11-10 23:09 — 设备端换网、手动蓝牙与热点重连

- 固件 0.1.19：网络菜单不再只在离线时可开；在线长按 ▲、离线长按 ▼ 打开，最后一项 `USE BLUETOOTH` 会保留配网记录并重启到 BLE 单栈。长按 ▼ 保留给 Agent 导航，避免功能冲突。
- 蓝牙模式标记改用 NVS 保存：实测 `RTC_DATA_ATTR` / `RTC_NOINIT_ATTR` 在 C3 的软件重启路径上不可靠，导致切蓝牙后又回到 Wi-Fi。
- 区分“自动回退”和“手动蓝牙”：自动回退在插回 USB 后恢复 Wi-Fi；手动蓝牙即使插着 USB 也保持 BLE，直到用户选回 Wi-Fi。
- 网络菜单打开期间链路断开或被重连事件触发时不再被强制关闭；关闭菜单后按当前在线状态回到原页面或离线页。
- `wifi` 控制命令拆分权限：`add` / `clear` / `list` 仍只接受 USB；`select` / `remove` / `ble` 可通过 USB、Wi-Fi 或 BLE 发送。
- Wi-Fi 断线重连改为 1→2→4→8 秒退避，取得 IP 后复位；避免手机热点或弱信号下立即重连形成风暴。
- Wi-Fi 状态新增 `rssi`，App 显示信号强度；低于 -75 dBm 时提示靠近手机或打开 iPhone「最大兼容性」。
- Mac App 0.2.13：切换 / 移除网络不再强制 USB，只要当前有已握手链路即可；新增「改用蓝牙」按钮，不清除已存网络。
- 每组网络记住最近一次设备局域网地址，连接时与 `host.local` 并行尝试；手机热点屏蔽 mDNS 时仍可用地址回退。
- 通过 Wi-Fi 切换网络时不再立刻断开本机连接，避免取消刚发出的切换命令。
- 验证：固件主机测试通过、ESP-IDF 构建通过；App 289 项单测与 AppUpdateKit 10 项通过。真机刷入 0.1.18 后：`wifi ble` 重启进入 BLE 单栈（无 IP），BLE 诊断 `transport=ble`、30,400 样本、`wirelessPassed=true`；`wifi select Plus` 恢复 Wi-Fi，Wi-Fi 诊断 `transport=wifi`、31,360 样本、`wirelessPassed=true`。0.1.19 只调整网络菜单手势（在线 ▲ / 离线 ▼），实体按键仍需手动复验。
