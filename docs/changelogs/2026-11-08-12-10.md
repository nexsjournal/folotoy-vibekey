# 2026-11-08 12:10 — 修复壁纸命令导致的固件栈溢出

- 真机握手发现 `Guru Meditation Error: Stack protection fault`（`ib_app`）：`ib_cmd_t` 加入 384 字符 Base64 后 `app_event_t` 约 1.1 KB，4 KB 的 `APP_TASK_STACK` 不够。
- `APP_TASK_STACK` 4096 → 8192；USB / BLE / Wi-Fi 接收任务不再在栈上创建事件，改为 `calloc` 后在 `xQueueSend` 复制入队并立即释放。
- 重刷后握手稳定；用测试图案走完 `start → 534 个分块 → done`，设备重启后从 `0x310000` 读回：`VKW1`、size 153600、CRC `0xde0e628f` 全部匹配；`clear` 后恢复默认猫图。
- App 设置页实机点击「应用到 Passport」显示“已应用”，再点「恢复默认」显示“已恢复默认背景”，USB 链路与重启流程通过。
