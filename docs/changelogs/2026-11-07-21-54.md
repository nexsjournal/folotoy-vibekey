# 2026-11-07 21:54 — Passport 支持切换 Agent 项目与会话

- 新增 `app/VibeKey/Vibe/AgentSessionCatalog.swift`：通过 Accessibility 只读 Codex / DeepSeek Honeycomb 侧栏，枚举项目、最近会话和当前窗口标题；按需展开折叠项目，选中后 AXPress 会话行并聚焦输入框。
- `DeviceBridge` 长按下键改为「应用 / 项目 / 会话」导航：Codex / DSH 显示 `PROJECT` 列表（`SWITCH APP` + `RECENT` + 项目），选中项目后显示 `SESSION` 列表；会话页长按下键返回项目页，项目页关闭。其他应用仍直接打开应用列表。
- 当前项目 / 会话前显示 `*`，默认选中；Codex 空项目提供 `NEW CHAT`；读取时显示 `SCANNING`，打开时显示 `OPEN SESSION`。
- 设置里的长按下键动作改名为「切换应用 / 会话」；补充 `IB_SESSION_PROBE` 调试探针。
- 文档：`docs/device-ui.md` 新增项目 / 会话 LIST 流程；`docs/architecture.md` 新增 `AgentSessionCatalogLoader → DeviceBridge → AppSwitcher.focusTextInput` 调用链；README 更新 Passport 说明。
- 原因：在 Passport 切换到 Codex / DSH 后，仍需要能选项目、选对话，选中后直接把光标放回输入框再说话。
- 验证：App 254 项测试、AppUpdateKit 10 项测试通过；真实 Codex（38 个项目、20 条最近会话）和 DSH（27 个项目）探针通过；Codex 项目展开、会话打开/返回、RECENT 打开均成功，DSH 项目展开、会话打开/返回、RECENT 打开成功。AX 只读标题，不读聊天正文。固件未改，不需要刷机。
- 已知限制：LIST 页仍只显示 ASCII，中文项目 / 会话名会转拼音并截断到 23 字节；目前支持 Codex 与 DSH NEXT，其他 Agent 需另加适配。
