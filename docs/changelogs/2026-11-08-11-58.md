# 2026-11-08 11:58 — Passport 离线页支持自定义像素壁纸

- 设置 › Passport 新增「离线页背景」：用户只选一张照片，Mac 端用 CoreGraphics 完成 3:4 居中裁切、60×80 像素化、Bayer 抖动、绿色单色化、顶部/底部暗带，输出 240×320 RGB565；不调用生图模型，也不上传原图。
- 新增 `WallpaperProcessor` / `WallpaperStore` / `WallpaperSection`：本地预览、上传进度、恢复默认；成功应用的预览保存在 Application Support，重启 app 后仍显示。
- 固件新增 `wallpaper` 分区（`0x310000/0x30000`）与 `ib_wallpaper` 模块：16 字节头（`VKW1` + size + CRC32）+ 153600 字节像素；启动时用 `esp_partition_mmap` 只读映射，magic / 大小 / CRC 任一不符就回退内置猫图，不占 150 KB RAM。
- 协议新增 `wallpaper` 命令：`start(size,crc)` → 设备擦除后回 `p:"start"` → 每块 288 字节 base64（`off,d`）→ `fin(1)` → 校验 CRC 后回 `p:"done"` 并重启；`clear(1)` 恢复默认。新增 Base64 解码与标准 CRC32 固件实现。
- 上传只走 USB / Wi-Fi；Mac 每块 6 ms 节流，避免 150 KB 分块把固件 16 条事件队列冲掉。

- 验证：固件主机测试（含壁纸 Base64 / CRC / 命令解析）、ESP-IDF 构建与分区检查通过；App 测试与 Release 构建通过。
