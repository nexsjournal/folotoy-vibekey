# 2026-11-08 13:35 — Wi-Fi 多网络与设备端切换

- 固件新增 `ib_wifi_store`：最多 4 组网络，每组独立 `SSID + password + host + PSK`；NVS 从旧 `ib_wifi/config` 自动迁移到 `ib_wifi/networks`，保留 cardid 与其他分区。
- USB `wifi` 命令扩展为 `add` / `select` / `remove` / `list` / `clear`；状态回报增加 `ssid`、`active`、`count`，列表不回传密码或 PSK。
- 设备离线时长按 ▼ 打开 `WIFI NETWORK` 列表：上下选择、OK 切换并重启 Wi-Fi、长按 OK 返回；30 秒无操作自动关闭。
- Mac 凭据改为网络数组并兼容旧单条 host/key；`WiFiClient` 同时尝试所有已保存的 `host.local`，设备换网后无需 USB 先同步。设置页增加已保存网络、当前标记、切换与移除。
- 新增网络表单不再自动填入当前 SSID，避免用户只点「添加并切换」就用空密码覆盖现有网络。
- 版本：app `0.1.9 (10)` → `0.2.0 (11)`，固件 `0.1.5` → `0.1.6`。
- 真机复测发现 `wifi list` 的 cJSON / newlib `sprintf` 调用使 3072 字节 USB 接收任务栈溢出重启；栈提升到 6144 字节后，`hello + wifi list + ping` 连续命令正常返回，`op:select` 重启后 NVS 与网络列表保持。
- 验证：固件主机测试 8 组通过、ESP-IDF 构建与 partition 检查通过；app 287 项测试与 AppUpdateKit 10 项测试通过；旧单网络已迁移为 `count=1`。真机用临时网络完成 `add → count=2 / active=1`、`select 原网络 → active=0`、`remove → count=1` 往返，重启后列表与 IP 均正确，临时记录已删除。
