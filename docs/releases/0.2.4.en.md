# FoloVibe Key 0.2.4

- The Passport READY page can now return to the Agent usage home. When usage is available the footer shows `TAP OK: USAGE`; tap OK to return, hold OK to talk as before.
- The USAGE token number is now 24 px, and the quota panel is taller with more readable `WEEK LEFT` / `RESET` / `PLAN` / `CREDITS` rows.
- Opening a session from project / session navigation now also keeps the current Agent's usage home available.
- Firmware is now 0.1.9 and the Mac app is 0.2.4.

Requires macOS 26 or later on Apple Silicon.

Install: install the Mac app first, then flash firmware 0.1.9 over USB. Open the DMG and drag `FoloVibe Key.app` to Applications.

Note: this build is Developer ID signed but not yet notarized by Apple. If macOS blocks the first launch, Control-click the app in Finder and choose Open.
