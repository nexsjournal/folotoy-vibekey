# FoloVibe Key 0.2.7

- The Passport Agent USAGE page now shows app-specific information: Codex keeps five-hour / weekly quotas; DSH shows context usage, session count, model, last activity and turns.
- Claude Code, ZCode and WorkBuddy now show local session / request / trace metadata, model and last activity instead of only NO DATA.
- Only local usage, model, timestamp and trace metadata is read; chat content is never read or stored.
- Firmware is now 0.1.11 and the Mac app is 0.2.7.

Requires macOS 26 or later on Apple Silicon.

Install: install the Mac app first, then flash firmware 0.1.11 over USB. Open the DMG and drag `FoloVibe Key.app` to Applications.

Note: this build is Developer ID signed but not yet notarized by Apple. If macOS blocks the first launch, Control-click the app in Finder and choose Open.
