# FoloVibe Key 0.2.6

- The Passport USAGE page now shows a `5H LEFT` five-hour quota alongside the weekly quota. The token number is 26 px and the redundant period caption is gone.
- `PLAN` and `CREDITS` share one compact row, and the quota panel is taller.
- Chinese project/session names and subtitles use a SemiBold CJK font, making 12 px Chinese text clearer on the device.
- Firmware is now 0.1.10 and the Mac app is 0.2.6.

Requires macOS 26 or later on Apple Silicon.

Install: install the Mac app first, then flash firmware 0.1.10 over USB. Open the DMG and drag `FoloVibe Key.app` to Applications.

Note: this build is Developer ID signed but not yet notarized by Apple. If macOS blocks the first launch, Control-click the app in Finder and choose Open.
