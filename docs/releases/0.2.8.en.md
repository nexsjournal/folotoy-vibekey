# FoloVibe Key 0.2.8

- The Codex USAGE page now shows separate reset countdowns under `5H LEFT` and `WEEK LEFT`.
- The two quota rows have more vertical spacing, with reset times on their own lines instead of crowding the next label.
- The generic USAGE panel adds optional `u1d` / `u2d` row details while keeping the old fields compatible.
- Firmware is now 0.1.12 and the Mac app is 0.2.8.

Requires macOS 26 or later on Apple Silicon.

Install: install the Mac app first, then flash firmware 0.1.12 over USB. Open the DMG and drag `FoloVibe Key.app` to Applications.

Note: this build is Developer ID signed but not yet notarized by Apple. If macOS blocks the first launch, Control-click the app in Finder and choose Open.
