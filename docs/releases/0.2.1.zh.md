# FoloVibe Key 0.2.1

首个 GitHub 公开安装包。

- 产品更名为 FoloVibe Key，安装包与 `/Applications` 应用名同步改为 `FoloVibe Key.app`。
- Passport Wi‑Fi 最多保存 4 个网络，每组独立主机名与 TLS-PSK；旧单网络配置自动迁移。
- 设备离线时长按 ▼ 可在硬件上切换已保存网络；Mac 会同时尝试所有已保存的主机名。
- 设置页支持添加、切换、移除网络，并显示设备当前网络和已保存数量。
- 保留 Codex / DSH / Claude / WorkBuddy / ZCode 等 Agent 的应用、项目、会话导航。
- 支持本机 Whisper、云端识别、实时双语字幕、AI 润色与 Passport 麦克风。

系统要求：macOS 26 或更高版本，Apple Silicon。

安装：打开 DMG，把 `FoloVibe Key.app` 拖入「应用程序」，首次启动按引导授予麦克风、辅助功能、蓝牙与本地网络权限。

说明：当前安装包使用 Developer ID 签名，但尚未完成 Apple 公证。若 macOS 首次阻止打开，请在访达中按住 Control 点击应用并选择「打开」。
