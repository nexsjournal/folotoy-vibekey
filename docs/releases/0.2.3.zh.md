# FoloVibe Key 0.2.3

- Passport 新增 Agent 用量首页：切换到 Codex、DSH NEXT、WorkBuddy、ZCode、Claude 等应用时先显示今日 / 本周 / 累计 Token、周额度、重置时间和套餐。
- 短按 OK 进入原来的 READY 页；长按 OK 直接从用量页开始录音；短按上下键切换周期；长按下键继续打开应用 / 项目 / 会话。
- Codex 读取官方 app-server 真实用量；DSH NEXT 读取本地会话的 tokenUsage 元数据，没有额度接口时明确显示 NO DATA。
- 固件升级到 0.1.8，新增 `usage` 协议与 USAGE 页面；Mac App 升级到 0.2.3。

系统要求：macOS 26 或更高版本，Apple Silicon。

安装：先安装 Mac App，再通过 USB 刷入固件 0.1.8；打开 DMG 把 `FoloVibe Key.app` 拖入「应用程序」。

说明：当前安装包使用 Developer ID 签名，但尚未完成 Apple 公证。若 macOS 首次阻止打开，请在访达中按住 Control 点击应用并选择「打开」。
