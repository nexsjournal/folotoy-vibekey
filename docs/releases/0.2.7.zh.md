# FoloVibe Key 0.2.7

- Passport 的 Agent USAGE 页现在按应用显示各自的信息：Codex 是 5 小时 / 每周额度；DSH 是上下文占用、会话数、模型、最近活动和轮次。
- Claude Code、ZCode、WorkBuddy 也会显示本地会话 / 请求 / trace 元数据、模型和最近活动，不再只是 NO DATA。
- 这些信息只读取本机的 usage、model、timestamp、trace 字段，不读取或保存聊天正文。
- 固件升级到 0.1.11，Mac App 升级到 0.2.7。

系统要求：macOS 26 或更高版本，Apple Silicon。

安装：先安装 Mac App，再通过 USB 刷入固件 0.1.11；打开 DMG 把 `FoloVibe Key.app` 拖入「应用程序」。

说明：当前安装包使用 Developer ID 签名，但尚未完成 Apple 公证。若 macOS 首次阻止打开，请在访达中按住 Control 点击应用并选择「打开」。
