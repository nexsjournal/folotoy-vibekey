# FoloVibe Key 0.2.4

- Passport 的 READY 页现在可以返回 Agent 用量首页：有可用用量时底部显示 `TAP OK: USAGE`，短按 OK 返回，按住 OK 仍然是说话。
- USAGE 页 Token 数字放大到 24 px，额度容器加高、行距拉开，`WEEK LEFT` / `RESET` / `PLAN` / `CREDITS` 更易读，底部空间不再空荡。
- 从项目 / 会话列表打开会话后，也会保留当前 Agent 的用量首页入口。
- 固件升级到 0.1.9，Mac App 升级到 0.2.4。

系统要求：macOS 26 或更高版本，Apple Silicon。

安装：先安装 Mac App，再通过 USB 刷入固件 0.1.9；打开 DMG 把 `FoloVibe Key.app` 拖入「应用程序」。

说明：当前安装包使用 Developer ID 签名，但尚未完成 Apple 公证。若 macOS 首次阻止打开，请在访达中按住 Control 点击应用并选择「打开」。
