# FoloVibe Key 0.2.8

- Codex USAGE 页在 `5H LEFT` 和 `WEEK LEFT` 下分别显示对应的重置倒计时。
- 两行额度之间增加间距，重置时间使用独立说明行，不再和下一行标签挤在一起。
- 通用 USAGE 面板新增 `u1d` / `u2d` 行说明字段，旧字段继续兼容。
- 固件升级到 0.1.12，Mac App 升级到 0.2.8。

系统要求：macOS 26 或更高版本，Apple Silicon。

安装：先安装 Mac App，再通过 USB 刷入固件 0.1.12；打开 DMG 把 `FoloVibe Key.app` 拖入「应用程序」。

说明：当前安装包使用 Developer ID 签名，但尚未完成 Apple 公证。若 macOS 首次阻止打开，请在访达中按住 Control 点击应用并选择「打开」。
