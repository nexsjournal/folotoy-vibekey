# FoloVibe Key 0.2.2

- Adds a Codex usage dashboard under Settings > Agent: today / this week / all-time tokens, weekly quota remaining, reset countdown, plan and reset credits.
- Reads the official Codex app-server account usage and rate-limit APIs; chat content is never read. If the server's daily bucket is not settled yet, only local token metadata is used for today.
- Missing Codex, sign-in, or timeout states are shown explicitly instead of fake zeros or sample numbers.
- Renames the former Vibe Coding settings page to Agent; the workflow and agent notification setup are unchanged.

Requires macOS 26 or later on Apple Silicon.

Install: open the DMG, drag `FoloVibe Key.app` to Applications, then follow the permission onboarding for microphone, accessibility, Bluetooth and local network access.

Note: this build is Developer ID signed but not yet notarized by Apple. If macOS blocks the first launch, Control-click the app in Finder and choose Open.
