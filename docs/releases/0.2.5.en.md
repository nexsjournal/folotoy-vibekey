# FoloVibe Key 0.2.5

- Fixed READY short-tap OK not returning to the Agent usage home. The tap window is now 500 ms, so a slightly slower tap still returns.
- Returning does not enter recognition and no longer flashes LISTENING on the device. Holding beyond 500 ms starts normal recording.
- Firmware stays at 0.1.9; only the Mac app needs updating.

Requires macOS 26 or later on Apple Silicon.

Install: open the DMG and drag `FoloVibe Key.app` to Applications.

Note: this build is Developer ID signed but not yet notarized by Apple. If macOS blocks the first launch, Control-click the app in Finder and choose Open.
