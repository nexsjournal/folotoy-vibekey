# FoloVibe Key 0.2.1

First public GitHub build.

- Renamed the product to FoloVibe Key; the app bundle and `/Applications` name are now `FoloVibe Key.app`.
- Passport stores up to four Wi-Fi networks, each with its own hostname and TLS-PSK; the legacy single-network record migrates automatically.
- Hold ▼ while Passport is offline to switch saved networks on the device. The Mac tries every saved hostname and adopts the one that completes TLS.
- Add, switch and remove networks from settings, with the current network and saved count shown in the app.
- Keeps app/project/session navigation for Codex, DeepSeek Harness, Claude, WorkBuddy, ZCode and other agent apps.
- Includes local Whisper, cloud recognition, live bilingual captions, AI polish and Passport microphone input.

Requires macOS 26 or later on Apple Silicon.

Install: open the DMG, drag `FoloVibe Key.app` to Applications, then follow the permission onboarding for microphone, accessibility, Bluetooth and local network access.

Note: this build is Developer ID signed but not yet notarized by Apple. If macOS blocks the first launch, Control-click the app in Finder and choose Open.
