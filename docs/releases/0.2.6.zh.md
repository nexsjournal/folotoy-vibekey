# FoloVibe Key 0.2.6

- Passport USAGE 页新增 `5H LEFT` 5 小时额度进度，和每周额度一起显示；Token 数字放大到 26 px，删除重复的周期标题行。
- `PLAN` 与 `CREDITS` 收成一行，额度区更高，底部空间利用更充分。
- 中文项目 / 会话名和字幕改用 SemiBold 中文字体，设备上的 12 px 中文更清晰。
- 固件升级到 0.1.10，Mac App 升级到 0.2.6。

系统要求：macOS 26 或更高版本，Apple Silicon。

安装：先安装 Mac App，再通过 USB 刷入固件 0.1.10；打开 DMG 把 `FoloVibe Key.app` 拖入「应用程序」。

说明：当前安装包使用 Developer ID 签名，但尚未完成 Apple 公证。若 macOS 首次阻止打开，请在访达中按住 Control 点击应用并选择「打开」。
