# FoloVibe Key 0.2.3

- Passport now opens an Agent usage home when you switch to Codex, DSH NEXT, WorkBuddy, ZCode, Claude and other agents: today / this week / all-time tokens, weekly quota, reset time and plan.
- Tap OK to enter the original READY page; hold OK to start recording directly from the usage page; tap ▲/▼ to switch periods; long-press ▼ still opens app/project/session navigation.
- Codex reads the official app-server usage; DSH NEXT reads local session tokenUsage metadata and shows NO DATA when no quota API exists.
- Firmware is now 0.1.8 with the `usage` protocol and USAGE page; the Mac app is 0.2.3.

Requires macOS 26 or later on Apple Silicon.

Install: install the Mac app first, then flash firmware 0.1.8 over USB. Open the DMG and drag `FoloVibe Key.app` to Applications.

Note: this build is Developer ID signed but not yet notarized by Apple. If macOS blocks the first launch, Control-click the app in Finder and choose Open.
