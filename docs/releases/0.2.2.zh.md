# FoloVibe Key 0.2.2

- 设置 › 智能体新增 Codex 用量看板：今日 / 本周 / 累计 Token、每周额度剩余、重置倒计时、套餐与重置券。
- 数据直接读取 Codex 官方 app-server 的账户用量与额度接口，不读取聊天正文；服务端今日桶尚未结算时，只用本机会话的 token 元数据补齐。
- 未安装 / 未登录 / 超时都会显示明确状态，不用 0 或示例数字冒充真实额度。
- 原来的 Vibe Coding 设置页更名为「智能体」，工作流与 Agent 通知配置保持不变。

系统要求：macOS 26 或更高版本，Apple Silicon。

安装：打开 DMG，把 `FoloVibe Key.app` 拖入「应用程序」，首次启动按引导授予麦克风、辅助功能、蓝牙与本地网络权限。

说明：当前安装包使用 Developer ID 签名，但尚未完成 Apple 公证。若 macOS 首次阻止打开，请在访达中按住 Control 点击应用并选择「打开」。
