# FoloVibe Key 0.2.5

- 修复 READY 页短按 OK 无法回到 Agent 用量首页的问题；短按窗口放宽到 500 ms，稍慢的轻点也能返回。
- 短按返回时不会进入识别，也不会在设备上闪现 LISTENING；按住超过 500 ms 才进入正常录音。
- 固件保持 0.1.9，无需重新刷机；只需更新 Mac App。

系统要求：macOS 26 或更高版本，Apple Silicon。

安装：打开 DMG 把 `FoloVibe Key.app` 拖入「应用程序」。

说明：当前安装包使用 Developer ID 签名，但尚未完成 Apple 公证。若 macOS 首次阻止打开，请在访达中按住 Control 点击应用并选择「打开」。
